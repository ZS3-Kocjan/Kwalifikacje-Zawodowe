## Instalacja

Projekt chodzi na Node.js v24.16.0

```bash
git clone https://github.com/ZS3-Kocjan/Kwalifikacje-Zawodowe.git
cd Kwalifikacje-Zawodowe/packages/web-site
npm i
```

## Uruchomienie

```bash
# w (ścieżce Kwalifikacje-Zawodowe/packages/web-site)
npm run dev
```

## Budowanie

```bash
# w (ścieżce Kwalifikacje-Zawodowe/packages/web-site)
npm run build
```
